Statically linked, cross-architecture Vim binaries for Linux built with GitHub Actions.

This repository only provides Vim binaries for ARMv6 / v7. 

For AArch64 & x86_64 support, please refer to the upstream repository: [heywoodlh/vim-builds.](https://github.com/heywoodlh/vim-builds/)

If you need a newer version or a custom build, feel free to fork either repository.
